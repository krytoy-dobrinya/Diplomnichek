# Diplomnichek

Developed with Unreal Engine 5 version 5.6.1.

# Project Setup

To clone use:
```
git clone https://github.com/krytoy-dobrinya/Diplomnichek.git
```

Then go to `[Path]\Diplomnichek` and open Diplomnichek.uproject with UE5.

# For work:
1. Change language to English in:
```
Edit -> Editor Preferences -> General -> Region & Language -> Editor Language-> English
```
3. Turn on force compilation at startup in:
```
Edit -> Editor Preferences -> General -> Loading & Saving -> Startup -> Force Compilation at Startup
```
